# VRC 压图（AVIF / WebP / JPG）

给 VRChat 玩家用的批量压图小工具。VRCX 开着的时候，游戏里拍的照片会把房间id、用户id写进PNG的XMP元数据里。普通压缩软件不会保留XMP数据，一压就把这些信息丢了；本工具会原样保留元数据。

保留元数据的同时，还能按需选择格式 AVIF / WebP / JPG
兼顾压缩率和兼容性

## 元数据是啥，为啥会丢，常规软件勾上保留原数据还是会丢？
因为VRCX 写的房间信息不在 EXIF 里，在 XMP 里（一个叫 iTXt 的文本块，命名空间 vrchat:Description）。XMP比EXIF冷门得多，一般只有相机才会写到EXIF里，很多软件都是服务于相机摄影，压根不解析它，常规软件勾了"保留元数据"也只是把 EXIF 搬走，XMP 直接无视就很蛋疼，没办法才让GLM搓了个这么个冷门软件。


PNG 文件里的元数据，VRC相关的就这三种：

| 类型 | 存在哪 | VRC 里的内容 |
|------|--------|-------------|
| XMP | PNG 的 `iTXt` 文本块 | VRCX 写的房间名、房间 ID、玩家名等 |
| EXIF | EXIF 块 | 拍摄时间、相机参数 |
| ICC | `iCCP` 块 | 色彩配置，这个一般虚拟拍照用不上 |

本工具的做法：转之前把 XMP / EXIF / ICC 从原图取出来，转的时候塞进新格式对应的地方（AVIF 的 meta 盒子、JPEG 的 APP 段这些），三种格式都保留。不想保留也可以，界面上有个"保留元数据"的勾选框，取消勾选就输出干净的图，方便分享。

## 选哪个格式

同样是 VRChat 截图（PNG 作为 100%基准）：

有损模式：

| 格式 | 建议 | 无损时体积 | 说明 |
|------|------|-----------|------|
| AVIF | 追求最高性价比 | ~60–85% | 压缩率最高，无损是"视觉无损"，不是逐像素 |
| WebP | 要无损 + 逐像素一致 | ~85–98% | 无损能做到像素级还原（含透明） |
| JPG | 要最大兼容 | — | 没有真无损，透明会变黑底 |

> 常规归档压缩建议就AVIF 420就够了 真要细细数毛可以把画质拉到95 像素444采样

> 无损模式：就是把像素直接抄一遍到新格式，AVIF 的无损走的是 YUV 转换，颜色会有一丁点取整误差（肉眼看不出），真要逐像素一模一样就选 WebP 的无损，量大的话不太建议444，慢的一批。


## 使用

直接双击AVIFBatchConverter.exe

界面参数：
- **输出格式**：AVIF / WebP / JPG
- **编码模式**：有损 / 无损（JPG 自动禁用无损）
- **画质**：1–100（无损时不可调）
- **色度子采样**：4:2:0 / 4:2:2 / 4:4:4，文字/UI 多的截图选 4:4:4 不糊边
- **编码速度**：1–10，越慢压得越狠
- **并行数**：1–16 进程
- 勾选项：保留元数据、保留透明通道、覆盖同名文件

建议搭配类似photoprism或immich类似的软件实现整理分类
