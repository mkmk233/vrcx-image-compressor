# VRC 压图（AVIF / WebP / JPG）

给 VRChat 玩家用的批量压图小工具。VRCX 开着的时候，游戏里拍的照片会把**当时在哪个房间、跟谁**这些信息写进 PNG 的元数据里。普通压缩软件只认像素，一压就把这些信息丢了；这个工具会**原样保留**，压完的图照样能在 VRCX / 图库看到房间和玩家信息。

保留元数据的同时，还能按需选择 **AVIF / WebP / JPG**、**无损 / 有损**、**4:4:4 子采样**（文字截图不会糊边）等选项。界面是深色左右分栏：左边加文件和调参数，右边实时显示进度和日志。

## 元数据是啥，为啥会丢

PNG 文件里除了画面，还能塞几段文字信息，VRC 相关的就这三种：

| 类型 | 存在哪 | VRC 里的内容 |
|------|--------|-------------|
| XMP | PNG 的 `iTXt` 文本块 | VRCX 写的房间名、房间 ID、玩家名等 |
| EXIF | EXIF 块 | 拍摄时间、相机参数 |
| ICC | `iCCP` 块 | 色彩配置，影响颜色准不准 |

关键是 XMP 这条：VRCX 把它写进 PNG 的文本块里，图片浏览器就是靠它显示"这图是哪屋拍的"。转成 AVIF/WebP/JPG 时，目标格式里没有 PNG 这种文本块，得靠工具把数据"翻译"到新格式对应的位置——大部分压图工具懒得做这一步，直接扔掉，于是图还是那张图，房间信息没了。

本工具的做法：转之前把 XMP / EXIF / ICC 从原图取出来，转的时候塞进新格式对应的地方（AVIF 的 meta 盒子、JPEG 的 APP 段这些），三种格式都保留。不想保留也可以，界面上有个"保留元数据"的勾选框，取消勾选就输出干净的图，方便分享。

## 选哪个格式

同样是 VRChat 截图（PNG 记为 100%）：

| 格式 | 建议 | 无损时体积 | 说明 |
|------|------|-----------|------|
| AVIF | 追求最小体积 | ~60–85% | 压缩率最高，无损是"视觉无损"，不是逐像素 |
| WebP | 要无损 + 逐像素一致 | ~85–98% | 无损能做到像素级还原（含透明） |
| JPG | 要最大兼容 | — | 没有真无损，透明会变黑底 |

> 细说一句"无损"：AVIF 的无损走的是 YUV 转换，颜色会有一丁点取整误差（肉眼看不出），真要逐像素一模一样就选 WebP 无损。

## 使用

```bash
pip install -r requirements.txt
python pngtoavif.py
```

界面参数：
- **输出格式**：AVIF / WebP / JPG
- **编码模式**：有损 / 无损（JPG 自动禁用无损）
- **画质**：1–100（无损时不可调）
- **色度子采样**：4:2:0 / 4:2:2 / 4:4:4，文字/UI 多的截图选 4:4:4 不糊边
- **编码速度**：1–10，越慢压得越狠
- **并行数**：1–16 进程
- 勾选项：保留元数据、保留透明通道、覆盖同名文件

## 打包 exe

```bash
pyinstaller --onefile --windowed --icon=app.ico --name AVIFBatchConverter pngtoavif.py
```

产物在 `dist/AVIFBatchConverter.exe`。
